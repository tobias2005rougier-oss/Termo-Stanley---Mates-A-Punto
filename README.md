# Mate a Punto

Landing page del termo Stanley Mate-System 1,2 L (proyecto académico).

- `index.html`: estructura de la página (modelo AIDA señalado con comentarios).
- `styles.css`: estilos.
- `script.js`: menú para celulares y formulario de suscripción a Mailchimp (doble opt-in).

## Ver la página

Publicada con GitHub Pages desde la rama `main`, carpeta raíz.
